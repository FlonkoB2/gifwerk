# Gifwerk

Gifwerk macht aus Videos GIFs in bestmöglicher Qualität, gedacht für Discord. Clip auswählen, Ausschnitt oder Kamerafahrt festlegen, Text dazu, auf Wunsch mit KI schärfer hochrechnen. Das GIF landet neben dem Video und in der Zwischenablage.

Funktioniert mit Videodateien und mit Links von Twitch und YouTube.

## Installieren

1. Unter **[Releases](../../releases/latest)** die Datei `Gifwerk-Setup-….exe` herunterladen.
2. Doppelklicken. Gifwerk wird ohne weitere Fragen installiert und startet.
3. Beim ersten Mal warnt Windows eventuell mit „Der Computer wurde durch Windows geschützt“. Das liegt daran, dass Gifwerk nicht kostenpflichtig signiert ist. Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.

Danach findest du Gifwerk auf dem Desktop, im Startmenü und per Rechtsklick auf ein Video unter **Mit Gifwerk öffnen**.

## Updates

Gifwerk schaut bei jedem Start nach, ob es eine neue Version gibt, und fragt dich dann, ob sie geladen werden soll. Das Update wird beim Schließen eingespielt oder sofort über **Jetzt neu starten**. Ein GIF, das gerade entsteht, wird dabei nie unterbrochen.

## Voraussetzungen

- Windows 10 oder 11 (64 Bit)
- Für das KI-Hochrechnen eine Grafikkarte mit Vulkan-Unterstützung (NVIDIA, AMD oder Intel)

## Deinstallieren

Windows-Einstellungen → Apps → Gifwerk → Deinstallieren. Desktop-Verknüpfung, Startmenü-Eintrag und Rechtsklick-Eintrag verschwinden dabei mit.
