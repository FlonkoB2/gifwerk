# GIF UP!

GIF UP! macht aus Videos GIFs in bestmöglicher Qualität, gedacht für Discord. Clip auswählen, Ausschnitt oder Kamerafahrt festlegen, Text dazu, auf Wunsch mit KI schärfer hochrechnen. Das GIF landet neben dem Video und in der Zwischenablage.

Funktioniert mit Videodateien und mit Links von Twitch und YouTube.

Bis Version 0.4.0 hieß das Programm **Gifwerk**. Wer es schon installiert hat, bekommt den neuen Namen einfach mit dem nächsten Update.

## Installieren

1. Unter **[Releases](../../releases/latest)** die Datei `GIF-UP-Setup-….exe` herunterladen.
2. Doppelklicken. GIF UP! wird ohne weitere Fragen installiert und startet.
3. Beim ersten Mal warnt Windows eventuell mit „Der Computer wurde durch Windows geschützt“. Das liegt daran, dass GIF UP! nicht kostenpflichtig signiert ist. Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.

Danach findest du GIF UP! auf dem Desktop, im Startmenü und per Rechtsklick auf ein Video unter **Mit GIF UP! öffnen**.

## Updates

GIF UP! schaut bei jedem Start nach, ob es eine neue Version gibt, und fragt dich dann, ob sie geladen werden soll. Das Update wird beim Schließen eingespielt oder sofort über **Jetzt neu starten**. Ein GIF, das gerade entsteht, wird dabei nie unterbrochen.

## Voraussetzungen

- Windows 10 oder 11 (64 Bit)
- Für das KI-Hochrechnen eine Grafikkarte mit Vulkan-Unterstützung (NVIDIA, AMD oder Intel)

## Deinstallieren

Windows-Einstellungen → Apps → GIF UP! → Deinstallieren. Desktop-Verknüpfung, Startmenü-Eintrag und Rechtsklick-Eintrag verschwinden dabei mit.
